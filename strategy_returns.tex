\section*{TDA + Machine Learning Strategy: Performance Results}
\noindent This document presents the results of a systematic trading strategy combining topological data analysis (TDA), machine learning, and multi-asset rotation. All backtests use \$100{,}000 initial capital, 0.1\% round-trip commission, and daily bar resolution over 2005--2024 (20 years).
\colorbox{benchbg}{Buy \& Hold} rows show the passive benchmark; \colorbox{bestbg}{\textbf{best strategy}} rows are highlighted in green.

\section*{How the Strategies Work}

\subsection*{Strategy Configurations}

Eight configurations are tested, each adding one component to isolate its contribution:

\begin{description}[style=nextline, leftmargin=2.5cm, font=\bfseries]
    \item[Buy \& Hold] Passive benchmark --- fully invested in the index at all times with no active trading.
    \item[TDA Adaptive] Uses \emph{persistent homology} (topological shape analysis) on price point clouds to detect market regime changes. Switches between long and flat positions based on topological complexity scores. No machine learning involved.
    \item[ML Ridge] Walk-forward Ridge regression model predicting 21-day forward returns from 21 features (TDA features + multi-horizon returns + volatility + technical indicators). Position size is proportional to model conviction. Refitted quarterly on an expanding window.
    \item[ML GBR] Same as ML Ridge but replaces Ridge regression with Gradient Boosted Regression (GBR) --- an ensemble of 100 decision trees that captures nonlinear feature interactions (e.g., momentum $\times$ volatility).
    \item[ML GBR + Smooth] Adds exponential signal smoothing ($\alpha = 0.15$) to the GBR model. A fast-exit override snaps the signal to the raw value when conviction drops sharply, preserving risk protection while reducing whipsaw trades.
    \item[ML Ridge + Rotation] Ridge model with \emph{multi-asset rotation}: when the ML model reduces equity exposure (low conviction), the freed capital is deployed into bonds (TLT) or gold (GLD), whichever has the highest 21-day momentum. Capital is never idle.
    \item[ML GBR + Rotation] GBR model with multi-asset rotation.
    \item[ML GBR + Sm + Rot] All three enhancements combined: gradient boosting, signal smoothing, and multi-asset rotation.
\end{description}

\subsection*{Key Concepts}

\begin{description}[style=nextline, leftmargin=4cm, font=\bfseries]
    \item[TDA / Persistent Homology] Prices are embedded into a point cloud via Takens' theorem (dimension 3, delay 5, window 60). Persistent homology computes topological features ($H_0$ components, $H_1$ loops) that detect structural market changes \emph{before} traditional indicators --- the shape of the data changes before price levels do.
    \item[Walk-Forward Training] The ML model trains on all data up to $t - 21$ days (expanding window) and refits every 63 bars (quarterly). This prevents look-ahead bias: the model never sees future data.
    \item[Signal Smoothing] An exponential moving average filter ($\alpha = 0.15$) smooths the raw ML signal, reducing noisy position changes. A fast-exit override bypasses smoothing when the raw signal drops sharply, ensuring the strategy can exit quickly during drawdowns.
    \item[Multi-Asset Rotation] When the ML model's equity conviction is below 100\%, the spare portfolio capacity ($1 - |$position$|$) is allocated to the highest-momentum alternative asset (TLT or GLD, ranked by 21-day return). This converts defensive signals into offensive returns.
\end{description}

\section*{Metric Definitions}

\begin{description}[style=nextline, leftmargin=4cm, font=\bfseries]
    \item[Total Return] Cumulative percentage gain over the full backtest period. A \$100{,}000 portfolio with +612\% return grows to \$712{,}000.
    \item[CAGR] Compound Annual Growth Rate --- the annualised return accounting for compounding. Allows comparison across different time periods.
    \item[Sharpe Ratio] Risk-adjusted return: (annualised return $-$ risk-free rate) / annualised volatility. Higher is better. Values above 1.0 are strong; above 1.5 is excellent.
    \item[Sortino Ratio] Like the Sharpe ratio but only penalises \emph{downside} volatility (negative returns). More relevant when returns are asymmetric --- a strategy that has large gains but small losses will score higher on Sortino than Sharpe.
    \item[Max Drawdown] The largest peak-to-trough decline during the backtest. Measures worst-case loss. A max drawdown of $-55\%$ means the portfolio lost more than half its value at its worst point.
    \item[Calmar Ratio] CAGR / $|$Max Drawdown$|$ --- return earned per unit of worst-case risk. Higher is better.
    \item[Volatility] Annualised standard deviation of daily returns. Measures how much the portfolio value fluctuates.
    \item[Trades] Number of round-trip trades (entry + exit) over the backtest period.
    \item[Sharpe Decay] Difference between in-sample and out-of-sample Sharpe ratio. Measures overfitting: a large negative decay suggests the strategy was overfit to training data. Near-zero decay indicates robustness.
    \item[P(Sharpe $> 0$)] Bootstrap probability that the strategy achieves a positive Sharpe ratio. Computed by resampling daily returns 2{,}000 times with replacement and measuring what fraction of resamples produce Sharpe $> 0$.
\end{description}

\bigskip
\noindent\textit{\textbf{Caveat:} The 28.7\% CAGR and 15{,}250\% total return reflect compounding of the rotation mechanism during crises rather than a sustainable edge. Forward returns should be expected to be substantially lower. See the full paper for additional limitations including transaction cost sensitivity, slippage assumptions, and survivorship bias.}
